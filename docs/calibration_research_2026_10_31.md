# 녹화된 트래커 모션으로 액터 골격과 부착 오프셋을 복원하는 방법

2026년 10월 31일 연구 결과. 대상은 `build/vs2022/Debug/recordings`의 기존 녹화와 매핑이며, 목표는 실제 액터 움직임의 충실도다. 이번 산출물은 재현 가능한 오프라인 실험과 다음 구현 설계다. 제품의 캘리브레이션·EXE에는 적용하지 않았다.

현재의 대칭 치수와 pole 기반 IK를 보정 결과의 기준으로 삼기보다, **액터의 고정 형태·부착 episode·시간별 자세를 분리하는 모델**이 적합하다. 기존 데이터는 초기화와 후보 비교에 충분히 유용하지만, 작은 센서 잔차만으로 해부학적 치수나 관절 중심을 확정할 수 없다. 따라서 자동화는 추정값과 불확실성·실패 사유를 함께 출력해야 한다.

## 확인된 부착 구조

| 역할 | 사용자 확인 위치 | 모델에서의 해석 |
|---|---|---|
| Head | 이마 | 두개골에 부착된 센서. HMD 눈 위치가 아님 |
| Chest | 가슴 중앙 또는 등 중앙 | 흉곽의 관측. 견갑골 자체의 관측은 아님 |
| Pelvis | 허리 앞 또는 뒤 | 골반의 관측. 장치 원점과 고관절·골반 중심은 다름 |
| Arm | 팔꿈치 근처 위팔 | 상완 분절의 위치와 회전 관측 |
| Hand | 손등 | 손 분절의 관측. 전완 센서가 아님 |
| Leg | 무릎 근처 허벅지 | 대퇴 분절의 위치와 회전 관측 |
| Foot | 발등 | 발 분절의 관측. 하퇴 센서가 아님 |

양쪽 위팔·손·허벅지·발을 포함한 11개 역할이다. 상완–손 사이에는 팔꿈치와 손목이, 대퇴–발 사이에는 무릎과 발목이 있다. 따라서 이 두 조합을 각각 하나의 관절을 공유하는 강체 쌍으로 피팅하면 안 된다. 가슴/등, 골반 앞/뒤 부착은 같은 시리얼이어도 별도 episode일 수 있다.

## 데이터와 실험 범위

- 세션 66개를 목록화했다. 10개 이상 역할이 매핑되고 10초보다 긴 세션은 23개, `frames.bin` 내용 해시가 같은 복제본을 제외하면 20개다. 이는 서로 독립인 20명의 액터를 뜻하지 않는다.
- 상세 비교는 `shouler_test`, `test__02`, `session_2026_06_06_023116`, `session_2026_06_27_144642`, `session_2026_06_27_165948`의 5개 녹화다. 원본 합계 68,154프레임 중 균일 간격 8,450프레임을 사용했다. 표본 내 역할별 유효 비율은 97.33–100%다.
- 상세 피팅은 각 시퀀스의 처음 65% 시간 구간을 계산에, 마지막 35%를 평가에 사용했다. 추가로 20개 고유 녹화에 동일한 간이 검사를 수행했다. 무작위 프레임 분할이 아니지만, 서로 다른 세션/액터나 독립 ground truth 검증과 동등하지 않다.
- 좌표는 m, quaternion은 xyzw이며 정규화했다. 유효 플래그·유한값·시간 증가·파일 헤더를 검사했다. 동일 장치 매핑이 동일 부착을 증명하지 않으므로 세션 간 offset을 묶지 않았다.
- Python 환경의 기존 NumPy 2.4.6과 SciPy 1.15.3을 사용했다. 제품 런타임 의존성은 추가하지 않았다.

## 비교한 방법과 결과

### 관절을 공유하는 두 분절의 중심 추정

가슴–위팔, 골반–허벅지에서 다음 식을 최소화했다.

`p_A(t) + R_A(t)c_A = p_B(t) + R_B(t)c_B`

두 로컬 중심 `c_A`, `c_B`를 동시에 추정하는 SCoRE 계열 원리다. [Ehrig et al.의 원 연구 초록](https://pubmed.ncbi.nlm.nih.gov/16293257/)은 두 분절이 함께 움직이는 경우를 다룬다. 이번 구현은 이 식에서 독립적으로 작성한 선형 최소제곱과 soft L1 보정이다.

5개 상세 녹화의 남겨둔 구간에서 강건 피팅의 3차원 중심 불일치 RMS는 대략 15–77mm였다. 고정된 단일 어깨 중심, 벨트/피부에 붙은 센서의 강체성, 유효 플래그가 표현하지 않는 추적 오차 등을 구분해야 한다. 이 값만으로 어느 원인이 지배적인지는 확정할 수 없다. 어깨 중심을 흉곽에 완전히 고정하는 가정은 특히 검증이 필요하다.

### 관측되지 않은 전완과 하퇴의 일정 길이 제약

위팔의 팔꿈치 후보와 손의 손목 후보 또는 허벅지의 무릎 후보와 발의 발목 후보 사이 거리를 사용했다.

`r_t = ||p_A(t) + R_A(t)a - p_B(t) - R_B(t)b|| - L`

미지수는 로컬 위치 offset 두 개와 길이, 총 7개다. multi start와 soft L1 손실을 사용했다. 수치 탐색 상자는 offset 각 성분 ±0.35m, 길이 0.10–0.70m이며, 이는 해부학적 합격 범위가 아니다. 별도 민감도 실험에서는 5mm 데이터 오차를 가정하고 0에 중심을 둔 offset prior를 추가했다. 실제 센서 잡음이나 실제 부착 위치를 측정한 prior가 아니다.

20개 고유 녹화에서 다음 결과를 얻었다. 원 장치 거리 baseline도 같은 scalar distance 잔차로 평가했다.

| 대상 | 원 장치 거리 잔차 RMS 중앙값 | 자유 offset 피팅 잔차 RMS 중앙값 | 피팅 길이 범위 |
|---|---:|---:|---:|
| 왼쪽 전완 후보 | 20.58mm | 5.35mm | 10.0–31.9cm |
| 오른쪽 전완 후보 | 25.54mm | 4.42mm | 16.9–65.7cm |
| 왼쪽 하퇴 후보 | 14.81mm | 6.41mm | 28.1–64.4cm |
| 오른쪽 하퇴 후보 | 15.61mm | 5.60mm | 35.8–69.9cm |

거리를 일정하게 만드는 데에는 도움이 되지만, 길이 결과에 분명히 채택할 수 없는 값들이 있다. 80개 자유 거리 피팅 중 3개는 수치 경계에 닿았고 1개는 종료 조건 내에 수렴하지 못했다. **3차원 관절 중심 불일치와 1차원 거리 잔차는 서로 다른 지표**다. 위 표의 작은 값은 관절 위치 정확도 4–6mm라는 뜻이 아니다.

`session_2026_06_27_165948`의 왼쪽 하퇴 길이를 고정해 재피팅하면, 40–64cm에서 평가 거리 RMS가 약 4.5–4.8mm로 비슷했다. `shouler_test`를 연속 5구간으로 나눠 각각 피팅하면 왼쪽 전완 후보는 18.9–26.2cm, 왼쪽 하퇴 후보는 31.2–62.7cm였다. 길이를 확정할 만큼 데이터와 모델이 일관되지 않는다.

40cm와 64cm인 두 후보를 비교하면 무릎 중심 후보는 38.60mm, 발목 중심 후보는 203.84mm 떨어져 있다. 이는 두 추정 해 사이 차이이지 실제 관절에 대한 오차가 아니다. 이처럼 자유 offset이 부적절한 길이를 보상할 수 있어 부착 위치에 대한 정보와 해부학적 검증이 필요하다.

### 회전축과 원 궤적 제약

손목/발목 중심을 위팔/대퇴 로컬 공간으로 옮기면 이상적 hinge 운동에서 원을 그린다. 원 평면·반지름·로컬 중심을 피팅하고, 위쪽 어깨/고관절 중심에 가장 가까운 축상의 점을 선택하는 모델도 시험했다. 마지막 선택은 분절 축과 hinge 축이 직교한다는 **해부학적 근사/좌표 convention**이다.

이상적인 합성 모델에서는 정답 길이·중심을 복원했다. 2mm 위치 잡음과 0.3도 회전 잡음을 넣은 단일 합성 실험에서는 길이 오차 약 0.46mm, 중심 오차 약 2.19mm였다. 이는 해당 이상적 모델의 결과이며 실제 사람에 대한 성능치가 아니다.

실제 데이터에서는 5구간 추정이 여전히 크게 달라졌다. 한 팔 사례는 평가 구간의 평면 잔차 RMS가 약 57mm였고, 한 다리 사례는 근위/원위 길이 비율이 비현실적으로 나왔다. 따라서 현재의 모든 동작에 이 모델을 강제하는 방안은 채택하지 않는다. 관절이 실제로 거의 hinge로 움직이는 구간을 분리하고, 축·길이의 구간 밖 재현성이 확인되는 경우에만 초기값으로 사용한다.

## 작게 맞는 오차와 실제 치수가 다른 이유

완전한 잡음 없는 합성 데이터로 다음을 확인했다.

1. 두 분절의 공유 ball joint는 충분한 다축 회전에서 6개 중심 좌표를 복원한다. hinge만 회전하면 축 방향 공통 이동이 남는다.
2. 원위 관절을 고정하고 hinge만 움직인 일정 길이 모델은 정답점에서 Jacobian rank가 3이었다. 프레임이 많아도 7개 미지수가 모두 결정되지 않는다.
3. 원위 관절을 별도로 충분히 움직여도 이상적 hinge에서 `a = C + h*n`, `L = sqrt(r*r + h*h)`인 연속 해가 남는다. 합성 반지름 26cm에서 축상의 중심을 0–20cm 옮기면 길이 26–32.8cm가 모두 같은 0 잔차를 낸다.
4. 알려진 정답, 수치 Jacobian 대조, 세계 좌표의 고정/시간별 공통 강체 변환 불변성을 검사했다. 순수 공통 원점 변환은 같은 프레임의 상대 보정식을 보존하지만 세계 이동·접지·속도 분석에는 원점 변경 이력이 필요하다.

센서 재부착을 포함한 별도의 합성 실험에서는 인접한 세 강체가 모두 관측된다는 조건에서, episode별 중심을 다시 추정하면 같은 31cm 분절 길이가 유지됐다. 이전 부착의 offset을 그대로 쓰면 이 예제의 관절 위치가 약 83.6mm 어긋났다. 현재 구성처럼 중간 분절이 없는 경우의 해결을 증명한 실험은 아니며, 체형과 부착을 분리해야 하는 이유를 검증한 것이다.

추가 합성 반례에서는 어깨 ball joint 연결과 손목 2축까지 포함한 사슬에서도, 팔꿈치 중심을 hinge 축상으로 옮기고 상완/전완 길이와 손목 영점을 함께 바꾸면 위팔·손 센서의 위치와 회전이 완전히 동일했다. 따라서 인접 체인을 추가하는 것만으로 해당 모델의 모호성이 자동 해소되지는 않는다. 모든 생체역학 모델에 대한 불가능성 증명이 아니라, 현재 관측과 미지의 관절 convention으로 가능한 구체적 반례다.

한 번의 full rank 또는 작은 최소제곱 잔차로 식별 가능성을 판정해서는 안 된다. 모델 불일치와 잡음이 원래 모호한 방향을 수치적으로 full rank처럼 만들 수 있다. parameter scaling·noise whitening·길이 profile·구간 bootstrap·prior 민감도를 함께 보아야 한다. 이번 구간별 범위는 정식 신뢰구간이 아니다.

## 권장 액터 모델과 최적화

형태 `beta`는 액터별 고정, 부착 `X[k,e]`는 장치/episode별 고정, 자세 `q[t]`는 시간별로 둔다. 센서 예측은 `T_hat[k,t] = G_segment(q[t], beta) * X[k,e]`다. 이 식의 `X`는 **분절→센서 변환**이며 현재 코드의 센서→타깃 변환과 방향을 혼동하지 않는다. 로컬 관절 anchor를 직접 표현하는 구현과 사용할 때는 자유로운 body frame과 mount를 동시에 중복 추정하지 않도록 gauge를 고정해야 한다.

형태 표현은 분절별 근위/원위 로컬 anchor, 관절의 axis/허용 자유도, reference frame으로 시작할 수 있다. 두 anchor가 자유 변수이면 길이는 둘의 거리에서 계산하고, 길이까지 별도의 독립 미지수로 중복시키지 않는다. 좌표 gauge는 기준 부착 episode의 분절 frame을 고정하거나 명시적 reference frame으로 제거한다. hinge 축상의 해부학적 중심을 택하는 직교 가정은 단순 좌표 gauge 제거가 아니라 추가 prior다.

최소 목적함수는 관측 센서의 위치 잔차와 SO3 회전 잔차, 관절의 허용 자유도, 명시적 형태 prior, 약한 시간 연속성이다. 위치 m와 회전 rad를 임의의 같은 수치 가중치로 합치지 않고 각각의 잡음 가정으로 정규화한다. 관절 연결과 분절 길이는 FK 또는 명시적 강체 제약으로 지킨다. 한 프레임마다 길이·부착을 자유롭게 바꾸어 관측을 흡수하지 않는다.

같은 tracker pose에서 구한 거리·중심 피팅 결과를 원 pose 관측과 함께 독립된 측정처럼 중복 가산하지 않는다. 기능적 피팅은 초기화와 모델 선택/진단에 쓰고, 공동 최적화에서 원 센서를 다시 사용할 때 그 의존성을 고려한다. 관절의 미세 이동을 허용하는 모델을 추가한다면, 그것은 명시적·제한된 joint 자유도로 두고 bone stretching과 구분해 검사한다.

| 부위 | 초기 복원 모델 | 현재 관측으로 확정할 수 없는 부분 |
|---|---|---|
| 골반과 대퇴 | 강체 골반, 좌우 고관절 중심, 강체 대퇴 | 피부/벨트 이동과 진짜 관절 이동의 분리 |
| 어깨 | 흉곽과 유효 어깨 중심, 상완 6DoF 관측 | 쇄골·견갑골 각각의 실제 움직임 |
| 팔꿈치와 전완 | 굽힘 hinge + 전완 회내/회외 + 손목 2축 근사 | 회전축상의 해부학적 중심, twist 분배·영점 |
| 무릎과 발목 | 기능적 무릎 hinge + 발목/후족 2축 근사 | 하퇴 축 회전과 발목 회전 분배, 발등 변형 |
| 몸통과 목 | 골반–흉곽–머리의 낮은 차원 연결 | 개별 척추뼈의 움직임 |

어깨 이동이나 무릎의 coupled rotation/translation은 데이터 밖 구간에서 재현 가능한 개선이 있을 때만 추가한다. 모델 복잡도를 늘리면 오차를 줄일 수 있지만 실제 해부학을 더 잘 안다는 증거는 아니다. frame convention·axis sign·각도 영점은 중립 자세 또는 명시적 좌표 정의로 고정한다. 이것과 측정되지 않은 해부학적 모호성은 별개다.

계산 순서는 유효 데이터/episode 분리 → 상대 운동의 충분성 검사 → 기능적 중심·축·체인 초기값 → 식별 가능한 형태 추정 → 명시적 prior를 포함한 형태/부착/자세 공동 보정 → 새로운 동작과 재부착 검증이다. 전 구간 batch 또는 sparse factor graph 최적화는 별도 worker에서 수행하고, 표시/실시간 재생은 고정된 결과를 사용한다.

첫 구현은 **골반–한쪽 허벅지–하퇴–발** 사슬로 범위를 좁혀 전체 데이터에서 검증하는 것이 적합하다. 관측되는 골반·대퇴·발의 6DoF를 모두 사용하고, 하퇴 pose만 latent로 둔다. 골반의 좌우 고관절과 root 이동을 분리하고, 접지는 확인된 구간에서만 보조 제약으로 쓴다. 반대쪽 다리·몸통·팔로 확장할 때에도 모든 actor/세션을 한꺼번에 같은 형태로 묶지 않는다.

코드 경계는 기존 binary reader → 순수 calibration 제약/품질 모듈 → actor kinematics/pose reconstruction → animation retargeting으로 둔다. Win32 UI와 녹화 thread가 수치 최적화를 직접 소유하지 않게 한다. `BodyProfile`은 필요하면 호환 초기값/출력 adapter로 남길 수 있지만, 추정된 actor model의 유일한 저장 형식으로 삼지 않는다.

## 다양한 대안의 판단

[O'Brien et al.의 6DoF magnetic motion 연구](https://arxiv.org/pdf/2303.10532)는 분절 transform들에서 서로 겹치는 로컬 관절점을 최소제곱으로 찾고, 알려진 치수의 기구로 검증한 직접적인 선행 사례다. 관절 양쪽 분절의 transform과 충분한 운동이 필요하며, 전완·하퇴가 관측되지 않는 이번 배치에 그대로 적용되지는 않는다.

[MinJointTracker](https://arxiv.org/html/2509.12398v1)는 센서 좌표계의 관절점을 상태로 두는 설계의 참고 사례지만, 각 강체 분절에 센서가 대응하고 동기화된 가속도계/자이로 측정을 사용하는 가정이 있다. 현재 binary의 pose/속도를 수치 미분해 가속도를 만드는 것은 새로운 독립 관측을 추가하는 것이 아니므로, 누락된 분절이나 정확히 같은 관측을 만드는 모호성을 해결했다고 볼 수 없다.

| 대안 | 활용 위치 | 이번 판단 |
|---|---|---|
| 단일 T pose와 인체 비율 | 빠른 시작값·좌표 영점 | 독립 치수 추정으로는 부족 |
| Fitted 방식 구 피팅과 기능적 중심/축 | 동작이 맞는 구간의 초기화 | 유용하나 모든 부위에 일괄 적용하지 않음 |
| 일정 길이와 원 궤적 피팅 | untracked forearm/shank 후보 | 데이터 일관성 개선, 치수 확정은 불가 |
| 전신 SE3/관절 제약 공동 최적화 | 권장 주 경로 | 다양한 구간과 prior 검증이 필요하며 아직 전신 구현 전 |
| 해부학적 template | 관절 타입·약한 형태 prior | template을 개인의 실측으로 표시하지 않음 |
| 학습된 motion/shape prior | 센서 결측·미관측 자유도 보완 | 그럴듯한 동작이 실제 동작을 대신할 수 있어 주 경로로 채택하지 않음 |
| 추가 landmark 또는 일시적 tracker 재배치 | 모호한 중심·축에 독립 정보 추가 | 정확도를 올리는 정보량이 큰 후보 |

[AddBiomechanics](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0295152)는 골격 스케일·marker offset·pose를 단계적으로 공동 최적화하는 선행 사례다. 이 녹화는 같은 anatomical marker/force plate 구성이 아니므로 해당 논문의 정확도·처리 시간을 전용할 수 없다. 힘 측정 없이 근육·관절 토크를 복원했다고 주장하지 않는다.

[SKEL](https://skel.is.tue.mpg.de/)은 단순 animation rig보다 생체역학적인 자유도를 다루는 참고 모델이다. [공식 라이선스](https://skel.is.tue.mpg.de/license.html)는 비상업 연구 등의 범위와 재배포 제한을 두므로 제품 의존성으로 채택하지 않았다. OpenSim/Ceres 등도 필요하면 별도 도입 평가를 하며 이번 연구에는 추가하지 않는다.

복원 치수의 정의도 명시해야 한다. 여기서 길이는 관절 중심 간의 기능적 길이이며 CT에서 뼈 표면 전체를 재는 치수와 같지 않다. 요골/척골·개별 척추·견갑골의 사실적인 mesh를 추가해도 그 형상과 움직임을 이 tracker 구성에서 개인별로 실측한 것은 아니다. 더 상세한 골격은 우선 약한 해부학적 모델로 두고, 데이터로 확인되는 자유도만 개인화한다.

## 정보를 늘리는 보정 녹화 제안

기존 녹화를 먼저 활용하되, 다음 중 필요한 동작을 짧게 추가하면 모호성을 줄이는 데 도움이 된다. 아직 실제 획득·정확도 검증한 프로토콜은 아니다.

1. **구분된 관절 동작**: 시작/끝의 편한 중립 자세를 기록하고, 골반을 크게 움직이지 않는 고관절 다축 운동과 위팔 다축 운동을 별도 구간에 넣는다. 손목을 고정한 팔꿈치 굽힘, 발목을 고정한 무릎 굽힘을 구분한다. 이어 전완/하퇴를 가능한 안정시킨 손목/발목 운동을 기록한다. 영상 없이 구간 명칭만으로 가정 준수를 보장할 수 없으므로 반복성으로 확인한다.
2. **동작을 보존하는 재부착 시험**: 같은 액터의 짧은 기준 동작을 sensor 재부착 전/후에 녹화한다. 치수는 같고 부착 변환만 달라져야 한다. 고정 morphology를 공유하는 비교는 동일 액터임을 명시한 경우에만 한다.
3. **독립 기준점 또는 일시적 재배치**: 기존 tracker 하나를 보정 시에만 전완/하퇴에 옮겨 누락 분절의 회전을 관측하거나, 강체 포인터의 tip을 pivot 보정한 뒤 뼈 landmark를 가리켜 기준을 얻는다. 재배치 episode는 원래 mapping과 분리한다. hinge 축상 중심의 해부학적 정의와 피부 움직임은 여전히 남으므로, 단순히 tracker를 추가했다고 완전한 실측이 되는 것은 아니다.

초기 합격 기준은 데이터 일관성, 재현성, 해부학적 정확도를 분리한다. 응용 목적에 맞는 위치/회전 허용치를 먼저 정하고, 분절 길이 불변·prior 변화에 대한 민감도·분리된 평가 구간·재부착 후 morphology 안정성을 검사한다. 해부학적 정확도 목표에는 독립 landmark/치수/다른 모캡 등의 참조가 필요하다.

실용적인 운영 목표는 액터의 해부학적 기준을 한 번 확보한 뒤, 매 부착마다 달라지는 offset을 자동으로 다시 맞추는 것이다. 예를 들어 hinge 축상의 해부학적 점 하나를 독립적으로 정하면 그 방향의 모호성을 줄일 수 있다. 길이 하나를 외부에서 정하는 경우에는 축상의 두 해가 남을 수도 있어 부호·방향 기준도 필요하다. 피부 위 landmark나 중립 자세의 정확도까지 완벽하다고 가정하지 않는다.

## 다음 구현의 완료 기준

첫 제품 단계는 모든 자동 추정값을 즉시 덮어쓰는 기능이 아니라 **세션 기반 보정 후보와 품질 진단을 생성하고 원본 tracker 위에 겹쳐 비교하는 도구**가 적합하다. 후보에는 SI 단위의 actor geometry, episode별 mount, 출처, prior, 미식별 방향, 해시·시간 구간, 평가 잔차를 함께 저장한다.

- 각 항목은 `data_identified`, `prior_conditioned`, `convention_defined`, `manual_reference`, `unidentifiable` 중 출처를 표시한다.
- 위치/회전 sensor fit, bone length drift, 관절 제약, foot contact, 추적 손실을 분리해 표시한다. anatomy reference가 없으면 anatomical accuracy는 `unknown`이다.
- prior에 의존하는 후보도 motion 복원에는 사용할 수 있지만, `accepted_for_reconstruction`과 `anatomically_validated`를 서로 다른 상태로 둔다.
- 합성 정답 회복·degenerate motion 거부·단위/좌표 불변·회전 및 원점 처리·추적 손실·같은 입력의 결정론을 검증한다.
- 현재 연구 결과에서 확정된 해부학적 캘리브레이션은 0개다. 자동 덮어쓰기나 기존 session snapshot 변경은 하지 않았다.

## 재현과 산출물

실행 진입점은 `research/calibration/run.py`다. 아래 순서로 실행하며, 결과는 `build/calibration_research`에 생성한다.

```text
python research/calibration/run.py catalog
python research/calibration/run.py synthetic_checks
python research/calibration/run.py limb_ambiguity
python research/calibration/run.py experiments
python research/calibration/run.py experiments --all-rich-unique --samples 700 --starts 4 --output-name sweep.json
python research/calibration/run.py sensitivity
python research/calibration/run.py hinge_experiments
python research/calibration/run.py summarize
python research/calibration/run.py plot_results
python research/calibration/run.py verify_artifacts
```

`catalog.json`은 원본 frames SHA256과 mapping 관계를 기록한다. `experiments.json`/`sweep.json`은 원 잔차와 파라미터, `sensitivity.json`은 길이 profile/구간별 결과, `hinge_experiments.json`은 추가 가정의 실패 사례, `synthetic_checks.json`은 합성 검증을 담는다. 그림은 PNG/SVG로 생성한다. 스크립트는 원본 녹화·매핑을 읽기만 한다.

Astra의 두 설계/실험 검토가 모두 완료됐다. 비식별성 결론은 위 합성 반례로 독립 확인했고, 재검토는 분절 anchor/axis line과 episode mount를 분리하는 오프라인 네 팔다리 모델을 권고했다. 구현은 한 다리로 관측·오차·길이 보존을 먼저 검증하고 같은 구조로 네 팔다리까지 확장하는 순서를 선택한다. 이는 네 팔다리 모델을 배제하는 설계가 아니라 검증 단계의 순서다.

검토 의견 중 원점 reset은 상대 보정과 세계 이동을 구분해 적용한다. 합성 검사상 같은 프레임의 공통 강체 변환은 상대 중심/길이식을 보존하지만, 세계 motion·접지·시간 연속성은 별도로 처리해야 한다. 원 궤적 피팅의 합성 성공과 실제 구간 실패도 구분했으며, 이를 완성된 actor 복원 성능으로 해석하지 않는다.

Astra에 원본 motion·device serial·API key는 전송하지 않았다. 2회 합계 15,307 tokens를 사용했고 helper의 보수적 사용량 비용 집계는 $0.70025다. 독립 청구서 금액이 아니다. `astra_design.txt`, `astra_review.txt`, `astra_usage.json`에 자문과 사용량을 보존했다. 의견은 연구 자문이며 실제 정확도 검증을 대신하지 않는다.
